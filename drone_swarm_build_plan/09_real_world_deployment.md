# Phase 09: Real-World Deployment

## Goal
Move from simulation to safe field deployment with real terrain, network constraints, and emergency behavior.

## Tasks

- [ ] Prepare test flight checklist
- [ ] Fly single drone in open area
- [ ] Fly single drone in rough terrain
- [ ] Fly two drones in formation
- [ ] Fly three drones in arc and curve formation
- [ ] Test local path planning with terrain hazards
- [ ] Test swarm communication in partial line-of-sight
- [ ] Test failover when one drone disconnects
- [ ] Test battery-aware return logic
- [ ] Test formation change on obstacle block
- [ ] Test storm or gust adaptation in a controlled environment
- [ ] Test map sharing and task reallocation
- [ ] Tune controller and planner parameters after data collection
- [ ] Run final mission rehearsal in a real mountain-like environment

## Deliverables

- Real swarm system works in field conditions
- Safety and fallback logic confirmed in real flight
- Swarm mission supports terrain-based autonomous exploration

## Exit condition

The swarm is ready for real-world rescue or exploration missions under controlled operational conditions.
